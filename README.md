# Specula Vision Dataset

A small, early-stage football computer vision dataset developed for **Specula**, an AI Sports Lab.

This repository contains a limited public sample of annotated football images in COCO format, intended for initial testing and experimentation.

## Dataset Information

- **Format:** COCO
- **Classes:** Player, Ball, Referee
- **Purpose:** Object detection and computer vision experiments
- **Creative Commons License**

## Private Dataset

Our main dataset is significantly larger and contains higher-quality, extensively annotated football images. For research inquiries or potential dataset access, contact help@speculasports.com

It is maintained privately with dedicated folders:

- `train/` — Training data
- `valid/` — Validation data
- `test/` — Testing data

Our exclusive datasets, advanced annotations, and proprietary research data are **not publicly available**.

The images in this repository are only a small experimental sample and do not represent the full quality, scale, or capabilities of Specula Vision.
